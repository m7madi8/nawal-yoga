# Start the Nawal site (Next.js)

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Production build:

```bash
cd web
npm run build
npm start
```

Vercel: set **Root Directory** to `web`.

Future (inactive) retreat HTML and assets are documented in `legacy/README.md` — do not delete them.
